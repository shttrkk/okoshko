# Инженерные решения

## 2026-10-26 Ф0

1. **Сквозной сценарий — главный приоритет.** Blueprint §6 задаёт интеграционный smoke: поиск → карточка → вопрос → ответ → паспорт → изменение → студия. Ширину каталога сокращаем раньше глубины этого пути.
2. **Сочи, bbox из исследования источников.** `region_selection.md` пока отсутствует. Начальный bbox `[39.65,43.55,39.80,43.65]` (lon/lat), цель 150–250 объединённых объектов OSM/Overture. Фактическое число покажем после сбора, без искусственного добивания.
3. **Два сервиса, один origin.** FastAPI раздаёт API, SPA и PMTiles; Postgres 17/PostGIS 3.6. Redis/pgvector не добавляем: до 250 отелей детерминированное ранжирование и вектор характеристик помещаются в память.
4. **Claims append-only.** Pydantic проверяет wire-схемы, PostgreSQL дополнительно гарантирует NOT NULL provenance, непустое evidence, confidence и TTL. Обновление создаёт новый claim; facts материализуются Resolver.
5. **Типизированные JSONB-документы.** Данные храним как `id,payload` с generated SQL-полями и индексами для provenance/геометрии. Это единый формат COPY seed и REST-контрактов, сокращающий интеграционные расхождения. Миграции и контракты меняются только через точку интеграции.
6. **Известные закреплённые версии, lock с хэшами.** Python 3.12.10; JS собирается на BUILDPLATFORM, Python amd64 использует только binary wheels. Версии из исследований не принимаем без успешной установки и сборки. Local tooling: pip 24.0 + pip-tools 7.4.1 (новый pip несовместим с этой версией pip-tools).
7. **Данные не равны симуляции.** Реальные геоданные и расчёт отделены флагом от симулятора отельера, mock карточек, fixture новой постройки и тестовых метрик. Отсутствие исходных данных даёт unknown, а не генерацию.
8. **Геодопущения раскрываются.** Copernicus — DSM, двойной учёт крыш предотвращаем оценкой земли; модель шума не является инструментальным измерением. Не называем Monte Carlo эмпирической точностью.
9. **Без API ключа.** Offline по умолчанию, whitelist инструментов, правила русского языка и cache. Live OpenAI-compatible LLM — опция, сетевых запросов в boot нет.
10. **Параллельная разработка.** Независимые части (данные, георасчёты, API, интерфейс) разрабатываются в отдельных ветках со своей зоной файлов; общие контракты и слияние в main проходят одну точку интеграции.


11. **LLM transport:** Chat Completions для совместимости с произвольным провайдером; native JSON Schema → JSON mode → prompted и один bounded repair, все ответы проходят Pydantic. Общий бюджет запроса 2,4 с, ошибка провайдера возвращает deterministic fallback. Формат проверен по [official Structured Outputs](https://developers.openai.com/api/docs/guides/structured-outputs?api-mode=chat) и [Chat Completions reference](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create). Live сеть не проверена без пользовательского ключа; transport tested MockTransport.

12. **Уточнение региона:** региональное исследование дописано после старта. Используем уточнённые зоны A `[39.690,43.555,39.790,43.635]` и B `[39.880,43.380,40.020,43.460]`. Финальный набор сначала250, включая60–80B, затем расширение к318 только при полном сквозном сценарии. 15/15 морских контрольных лучей не подменяют LOS от номера. Мини-расписание не выдумываем при отсутствии подтверждённого источника.

13. **Запускаемость и безопасность:** чистый клон с пустым build cache проверяем на каждой контрольной точке и после последнего коммита; startup читает только локальные seed. GitHub workflow только workflow_dispatch, локально make check + make audit. Известные Python advisories и npm production High/Critical блокируют готовность. Фактическое число отелей показываем из API, а не число318 из планового исследования.

14. **Первый dependency audit исправлен:** FastAPI0.162.0 + Starlette1.10.0, MapLibre6.16.0 и React Router7.18.4. Базовые образы обновлены до Python3.12.15 и Node22.23.4 (официальный Docker Hub tag inventory). Повторный pip-audit/npm audit production:0 advisories. Старые версии из Ф0 заменены после измеренного аудита, не исключениями.

15. **Подтверждение условий и синтетический demo seed:** confidence геомодели наружного шума остаётся0.38; оценки не поднимаем ради теста. В поставке есть три отдельные synthetic=true цитаты симулятора (Cascade SW/3, Приморская W/5, Brevis W/7, сентябрь), доступные в публичном ledger и видимые badge в выдаче. Это вымышленные ответы, не заявления реальных отелей. По требованию приёмки «✓ или ≈, confidence ≥ 0,6» группа all допускает только выполненное сравнение с confidence≥0.6; сам verdict при confidence<0.7 остаётся≈. Частичность из-за неизвестного веса питомца, общего заявления о виде, конфликтов или несовместимых scopes не засчитывается. Demo-check обязан проверять synthetic label и отдельно наличие реальных low-confidence noise facts.

16. **Компактное хранение:** логический URI GeoJSON и hash несжатых bytes сохраняем, физический файл gzip mtime0. Geo read helper и HTTP Content-Encoding обеспечивают совместимость без нового научного расчёта. Неиспользуемые дубли buildings/osm_features CSV удаляем; источником геометрии остаётся один GeoJSON gzip.

17. **Полный dependency gate:** make audit включает runtime/dev/pipeline Python locks, npm full и prod; scanner error или skipped dependency блокирует PASS. Исправлены 10 dev advisories обновлением pip26.2.2, setuptools84.2.1, pytest9.1.1 и совместимых инструментов; не suppress.

18. **Сдача.** Готовим проверенный коммит main и тег `submission` локально; push в репозиторий команды и настройки публичности выполняет владелец репозитория.

19. **Ограничения маршрута:** Criterion дополнен no_stairs/no_crossings(defaultfalse). Одна beach_walk описывает distance/time и дополнительные AND-ограничения маршрута; missing flags означаютunknown, не отсутствие лестниц. «Коляска» делает no_stairs=true, это видно пользователю. Боковойзакат подписываем по геометрии, не меняя ранее рассчитанные числа без новой версиигеоданных.

20. **Частичные POI наблюдения:** неизвестный въезд автомобиля не отменяет измеренное расстояние до парковки. Resolver сохраняет известные числовые расстояния car/family/pharmacy как computed, значение available остаётсяnull. Только сравнение известного поля может быть≈; available=null никогданестановится✓. local_poi_lookup@2 даёт confidence0.65 физическому расстоянию (тотжеприорOSMнаблюдений), неразрешениюуслуг. Архивныеclaims/dates не изменяются, manualrecollectсоздаётновуюзапись.

21. **Freshness без фиктивной свежести:** повтор георасчёта над теми же inputSHA не является новым наблюдением. Watcher сравнивает физические snapshots с evidence, сохраняет stale и исходныйvalid_until при неизменных данных; новый source hash разрешает пересчёт. Симулятор тоже не превращается в реальноеобновление.

22. **История сохраняется полностью.** Не выполняем squash, filter или orphan и не создаём новый корневой коммит ради размера: полная история важнее мягкой цели 150 МБ для Git pack. Отслеживаемые файлы не больше 50 МБ, полезные данные уже сжаты gzip/LZMA, исторические генерации сохраняются. Push выполняет владелец; ссылки добавляются при полной готовности.

23. **Чистый запуск.** Тестовый драйвер может использовать локальные QA-инструменты, но Compose запускается с PATH, содержащим только Docker CLI, плагины и credential helpers; Python и Node на хосте для запуска продукта не нужны. Отдельный прогон без `.env` фиксирует отсутствие файла явно. Зависимости браузерного прогона подключаются только после health и не являются ручным шагом запуска приложения.


24. **Недоверенный LLM вывод не имеет полномочий.** Предложение парсера не содержит source/confidence/identity/confirmed/dates; разрешены только поля характеристики и проверяемые цитаты. Server principal задаёт hotel scope и synthetic; demo accounts всегда synthetic. Bearer нужен для private writes/cabinet; HttpOnly SameSite=Strict cookie с Path=/api/runs обслуживает только чтение SSE. Production SSO и отзыв гостевых capability — отдельная работа, не заявленная готовность.

25. **Сравнение с фильтрами — модельная метрика.** Базовый фильтр — расстояние точки отеля до OSM coastline ≤500 м; основной — совместимые facade/floor/month море+закат, confidence≥0,6, сентябрь. Unknown не считается отрицательным. 20 кандидатов вне радиуса — дополнительное модельное покрытие, а не измеренный рост продаж или проверка каждого окна.

26. **Покрытие считает только исполняемый продуктовый Python.** pytest-cov исключает backend/tests и geo/tests. Отчёт сохраняет все остальные backend/geo модули, включая слабее покрытые views/walk, без искусственного порога сдачи. Runtime зависимости не расширяются: plugin только в dev lock.


27. **Повтор демо сохраняет историю.** Полный сценарий с новым домом меняет факты и законно снижает число совпадений Маши с 3 до 2. Для исходного сценария используется отдельный локальный Compose project `okno-demo` (настройка только в ignored .env); прежний `okno` и его volumes сохранены. Claims/events/passports не удаляются и не переписываются ради приёмки. Чистый клон начинает собственную исходную БД, поэтому baseline demo-check запускается до изменений или в изолированном проекте.
